# Security Policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, bypass of the
sensitive-field filter, or leaked credential. Use the repository's
**Security > Advisories > Report a vulnerability** flow:

https://github.com/Jascenn/sensitive-guard/security/advisories/new

Include the affected command, operating system, reproduction steps, expected
redaction, observed output, and impact. Use synthetic values only; never send a
real API key, token, password, or private configuration file.

Reports are handled on a best-effort basis. Please allow time for validation
and a coordinated fix before public disclosure.
